Public Attributes

float azimuth
 Object azimuth pointing angle (right-hand rule) on vehicle sprung mass Z-axis as defined by ISO 23150:2023. 0 = Object pointing forward. Positive values = Object pointing toward the left side of the vehicle. Negative values = Object pointing toward the right side of the vehicle.
 
float elevation
 Elevation to target point measured as angle between the vehicle sprung mass XY-plane as defined by ISO 23150:2023 at the object reference point and the direction to the target point. 0 = Object pointing at a target at the same height as the object reference point. Positive values = Object pointing at a target above the object reference point. Negative values = Object pointing at a target below the object reference point.
