int16_t x
 Longitudinal position of object reference point measured on the X-axis of the vehicle rear-axle coordinate system as defined by ISO 23150:2023. The object reference point refers to a representative point of the object. Positive values = forward of (first) rear- axle. Negative values = backward of (first) rear-axle.
 
int16_t y
 Lateral position of object reference point measured on the Y-axis of the vehicle rear-axle coordinate system as defined by ISO 23150:2023. The object reference point refers to a representative point of the object. Positive values = left of rear-axle center. Negative values = right of rear-axle center.
 
int16_t z
 Height position of object reference point measured on the Z-axis of the vehicle rear-axle coordinate system as defined by ISO 23150:2023. The object reference point refers to a representative point of the object. Positive values = above center of rear-axle reference point. Negative values = below center of rear-axle reference point.
 
float yaw
 Object yaw angle, measured from the vehicle sprung mass X-axis as defined by ISO 23150:2023 to the object X-axis, around the vehicle Z-axis (right-hand rule). 0 = Object in nominal orientation. Positive values = Object rotated left. Negative values = Object rotated right.
 
float pitch
 Object pitch angle, measured as angle from vehicle sprung mass XY-plane as defined by ISO 23150:2023 to the object X-axis. 0 = Object in nominal orientation. Positive values = Object tilted up. Negative values = Object tilted down.
 
float roll
 Object roll angle about the object X-axis (right-hand rule). 0 = Object in nominal orientation. Positive values = Object tilted to the right. Negative values = Object tilted to the left.
